## 実機確認手順

1. `output/pdf/fnd-07-a5-label-prototype.pdf`を対象ブラウザで開く。
2. プリンターの用紙をA5縦に設定する。
3. 倍率を100%または「実際のサイズ」に設定する。
4. ブラウザ側のヘッダーとフッターを無効にする。
5. 1枚だけ印刷する。
6. 100 mm確認線を定規で測る。
7. 四辺の欠け、文字化け、にじみ、給紙方向を確認する。
8. 3 m程度離れてコンテナIDと重量を識別できるか確認する。
